# Data Structures - Unit 1 & Unit 2

This repository contains **C++ implementations** of fundamental data structures for academic learning and practice.

## 📂 Contents

### Unit 1
- **Stack (Array Implementation)**
  - Push, Pop, Display
- **Array Operations**
  - Insert, Delete, Traverse
- **Recursion (Factorial)**
  - Demonstrates recursive function calls

### Unit 2
- **Queue (Array Implementation)**
  - Enqueue, Dequeue, Display
- **Circular Queue (Array Implementation)**
  - Efficient memory utilization with wrap-around
- **Singly Linked List**
  - Insert at beginning, end
  - Delete at beginning, end
  - Display all nodes
